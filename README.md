# DRAVYADEX 1.0 — Digital Ayurvedic Dravyaguna Knowledge Platform

> *“Explore the Science of Nature.”*

A modern digital knowledge platform for exploring Ayurvedic medicinal plants, classical Dravyaguna properties, botanical identities, pharmacological classifications, and documented research.

---

## Overview

DravyaDex integrates 483 medicinal plant taxa, 3,593 PubMed research papers, 106 AFI formulations, 816 compounds, and 277 lexicon terms across classical and contemporary sources.

- **Frontend:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Lucide Icons
- **Motion & 3D:** React Three Fiber, Drei, Motion for React, Canvas shaders
- **Backend & Database:** PostgreSQL, Supabase, Full-text Search, pg_trgm fuzzy matching
- **Open Access Development Mode:** All features accessible without mandatory login barriers.
